# Применение методов каузального вывода при анализе зависимостей между оптимизирующими проходами LLVM-компилятора

**Магистерская диссертация** · МФТИ, кафедра ВЦ РАН

Метод обнаружения каузальных зависимостей между парами оптимизирующих проходов LLVM на основе рандомизированного эксперимента и модели потенциальных исходов.

## Аннотация

Качество кода, генерируемого оптимизирующим компилятором, существенно зависит не только от выбора проходов, но и от порядка их применения (*phase ordering problem*). Существующие подходы анализируют корреляции между порядком проходов и метрикой качества кода, что не позволяет отделить причинно-следственные зависимости от случайных совпадений.

В работе показано, что случайные перестановки проходов образуют **рандомизированный эксперимент** в смысле Неймана–Рубина: средний эффект порядка пары проходов (ATE) совпадает с каузальным эффектом без необходимости устранения конфаундеров алгоритмами поиска структуры (PC и аналоги).

## Ключевые результаты

- **92,7 % статистически значимых корреляций** между порядком пар проходов и улучшением метрики **не имеют каузальной природы** (608 каузальных рёбер против 5124 корреляционных на одних и тех же данных).
- **Гетерогенность эффектов:** до 29 % рёбер глобального графа меняют знак на отдельных кластерах программ — универсального оптимального порядка не существует.
- **Две формулировки воздействия** выявляют разные классы зависимостей: относительный порядок (608 рёбер, глобальные эффекты) против непосредственного соседства (44 ребра, локальные синергии).
- **Содержательный граф (372 ребра):** после фильтрации смещения метрики структура воспроизводит инженерные паттерны пайплайна `-Oz` (например, `gvn → instcombine → dse`).
- **Собранные датасеты:** 517 бенчмарков в LLVM IR и 5,17 млн прогонов с измеренной метрикой.

## Эксперимент

| Параметр | Значение |
|----------|----------|
| Компилятор | LLVM 16, legacy pass manager (`-enable-new-pm=0`) |
| Набор проходов | 89 проходов (перемешиваемых), список в `thesis/parts/appendix.tex` |
| Бенчмарки | 517 (lac-dcc — 231, AnghaBench — 286) |
| Прогонов | 5 170 000 (10 000 на бенчмарк) |
| Длина последовательности | случайная из [10, 40], выборка без повторений |
| Метрика | число LLVM IR-инструкций |
| Baselines | `raw` (без оптимизаций), `-Oz` |

**Пайплайн анализа:** ATE для всех 3916 пар → тест Уэлча → коррекция Бенджамини–Хохберга (FDR 0,05) → построение графа (порог `|ATE| ≥ 0,005`). Графы строятся на трёх уровнях: глобальный, по 8 доменным классам (per-class), по 6 структурным кластерам (per-cluster). CATE оценивает гетерогенность эффектов по подгруппам.

## Структура проекта

```
.
├── thesis/                     # Текст диссертации (LaTeX)
│   ├── main.tex
│   ├── parts/                  # Аннотация, главы 1–7, приложение
│   ├── images/                 # Рисунки результатов
│   └── references.bib
│
├── src/
│   ├── config.py               # Пути LLVM, 89 проходов, классификация бенчмарков
│   ├── compile_benchmarks.py   # Компиляция lac-dcc → .bc
│   ├── compile_anghabench.py   # Компиляция AnghaBench → .bc
│   ├── download_anghabench.py
│   ├── metrics.py              # Подсчёт IR-инструкций (llvm-dis → парсинг .ll)
│   ├── experiment.py           # Генерация последовательностей, прогон opt, параллелизация
│   ├── features.py             # Извлечение IR-фичей для кластеризации
│   ├── clustering.py           # Кластеризация программ (PCA + KMeans)
│   ├── visualization.py        # Визуализация графов и результатов
│   └── analysis/
│       ├── ate.py              # ATE + BH-FDR + построение графов (шаги 1–3)
│       ├── cate.py             # CATE per-class / per-cluster / per-benchmark
│       └── correlation.py      # Корреляционный граф для сравнения
│
├── benchmarks/
│   ├── classes.csv             # Ручная классификация по доменам (8 классов)
│   ├── clusters.csv            # Структурная кластеризация (6 кластеров)
│   └── clustering_*.png
│
└── experiments/
    ├── analysis/               # Результаты каузального анализа
    │   ├── variant_B/          # Относительный порядок
    │   └── variant_V/          # Непосредственное соседство
    └── figures/                # Графики (графы, CATE, сравнения)
```

Для каждого варианта воздействия в `experiments/analysis/`:
`ate_*` — таблицы ATE, `graph_*` — рёбра каузальных графов, `corr_*` — корреляционные графы,
`cate_*` — гетерогенность эффектов, `comparison_causal_vs_corr.csv` — сводное сравнение.

## Воспроизведение

```bash
# LLVM 16
brew install llvm@16

# Python-окружение
python3 -m venv .venv && source .venv/bin/activate
pip install pandas pyarrow numpy scikit-learn matplotlib

# 1. Компиляция бенчмарков в LLVM bitcode
python src/compile_benchmarks.py
python src/compile_anghabench.py

# 2. Эксперимент (5.17M прогонов; результаты в experiments/results/*.parquet)
python src/experiment.py

# 3. IR-фичи и кластеризация
python src/features.py
python src/clustering.py

# 4. Каузальный анализ (обе формулировки воздействия)
python -m src.analysis.ate --formulation B
python -m src.analysis.ate --formulation V
python -m src.analysis.cate
python -m src.analysis.correlation

# 5. Визуализация
python src/visualization.py
```

> Сырые данные эксперимента (`experiments/results/*.parquet`, ~500 МБ) и скомпилированные
> `.bc` не хранятся в репозитории (см. `.gitignore`). В git лежат агрегированные результаты
> анализа (CSV) и рисунки.
