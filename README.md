# Compiler Pass Sequence Optimization via Causal Inference

**Магистерская диссертация**
Кафедра ВЦ РАН «Проектирование и операционные системы»

Применение методов каузального вывода для оптимизации последовательностей проходов компилятора

## Аннотация

Проблема фазового упорядочивания (phase ordering problem) в оптимизирующих компиляторах заключается в том, что порядок применения оптимизационных проходов существенно влияет на качество сгенерированного кода. Традиционные подходы основаны на корреляционных графах, которые строятся из успешных последовательностей, но содержат множество ложных зависимостей.

**Цель работы:** Построить каузальный граф зависимостей между оптимизационными проходами компилятора и использовать его для генерации оптимальных последовательностей проходов для конкретных программ.

**Основной результат:** Применение методов каузального вывода (Average Treatment Effect, CATE, PC-algorithm) позволяет отделить истинные причинно-следственные связи между проходами от ложных корреляций. Построенный каузальный граф содержит **358 значимых каузальных связей** между 52 проходами LLVM, что позволяет генерировать оптимизированные последовательности для минимизации размера кода.

## Основные результаты

### Каузальный граф оптимизационных проходов

**Построен граф из 358 каузальных связей** между 52 проходами LLVM на основе 95,000 экспериментальных прогонов на 19 программах из cBench.

**Методы каузального вывода:**
- **ATE (Average Treatment Effect)**: Идентификация парных каузальных эффектов
- **CATE (Conditional ATE)**: Гетерогенные эффекты для разных типов программ
- **PC-algorithm**: Отсеивание ложных корреляций через условную независимость
- **Позиционный анализ**: 15 проходов с сильными предпочтениями по позиции (рано/поздно)

### Применение для оптимизации размера кода

Каузальный граф используется для генерации оптимизированных последовательностей проходов:

**Топ-5 программ по эффективности оптимизации:**
| Программа | Baseline (-Oz) | Улучшение | Описание |
|-----------|----------------|-----------|----------|
| dijkstra | 10,928 байт | **87.3%** seq. beat -Oz | Алгоритм Дейкстры |
| sha | 11,776 байт | **80.9%** | SHA хеширование |
| crc32 | 8,400 байт | **79.7%** | CRC32 контрольная сумма |
| bitcount | 16,512 байт | **77.6%** | Подсчёт битов |
| stringsearch1 | 17,600 байт | **73.0%** | Поиск подстроки |

### Ключевые выводы

1. **Каузальный граф >> Корреляционный граф**: 358 истинных связей vs 2652 корреляций (98.6% — ложные)
2. **Гетерогенность эффектов**: Оптимальные последовательности сильно зависят от типа программы
3. **Позиционные эффекты**: Некоторые проходы (strip, instnamer, loop-*) имеют сильные предпочтения по позиции
4. **Практическая применимость**: Для простых программ (crc32, bitcount) короткие целевые последовательности дают огромный выигрыш

## Технологический стек

- **LLVM 16** (последняя версия с legacy pass manager)
- **Python 3.9+** (NumPy, SciPy, statsmodels для каузального анализа)
- **cBench** (19 бенчмарков: crypto, multimedia, telecom, automotive)
- **Методы**: ATE (Average Treatment Effect), CATE, PC-algorithm, Benjamini-Hochberg FDR коррекция

## Воспроизведение экспериментов

### Установка зависимостей

```bash
# LLVM 16
brew install llvm@16

# Python зависимости
pip3 install numpy scipy statsmodels
```

### Компиляция бенчмарков

```bash
python3 src/setup_benchmarks.py
```

### Запуск экспериментов

**Эксперимент 1: Фиксированная длина (52 прохода)**
```bash
python3 src/run_experiment.py \
    --benchmarks-dir ./benchmarks/compiled \
    --num-iterations 2500 \
    --output experiments/exp1_fixed_length/raw_results.json
```

**Эксперимент 2: Переменная длина (10–30 проходов)**
```bash
python3 src/run_experiment_variable.py \
    --benchmarks-dir ./benchmarks/compiled \
    --num-iterations 5000 \
    --min-length 10 \
    --max-length 30 \
    --output experiments/exp2_variable_length/raw_results.json
```

### Каузальный анализ

```bash
# Для эксперимента 1
python3 src/causal_graph_discovery.py \
    --input experiments/exp1_fixed_length/raw_results.json \
    --output-dir experiments/exp1_fixed_length/causal_graph

# Для эксперимента 2
python3 src/causal_graph_discovery.py \
    --input experiments/exp2_variable_length/raw_results.json \
    --output-dir experiments/exp2_variable_length/causal_graph
```
