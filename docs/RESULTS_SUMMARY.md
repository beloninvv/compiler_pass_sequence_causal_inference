# Построение каузального графа оптимизационных проходов

## Методология

Для построения каузального графа проведены эксперименты с **переменной длиной** последовательностей (10–30 проходов), что обеспечивает достаточную вариацию для идентификации каузальных эффектов. Дополнительно проведён контрольный эксперимент с фиксированной длиной для сравнения подходов.

## Почему переменная длина даёт больше каузальных рёбер?

### Проблема фиксированной длины
- Все 52 пасса **всегда присутствуют** → сильная корреляция между пассами
- Нельзя отличить:
  - "Пасс A полезен сам по себе"
  - "Порядок A→B важнее, чем B→A"
- Эффекты усредняются по всем последовательностям → ATE ≈ 0
- Большинство парных эффектов **confounded**

### Преимущества переменной длины
- Пассы могут **присутствовать или отсутствовать** → больше вариации
- Можем измерить:
  - Маргинальный эффект пасса (есть vs нет)
  - Эффект взаимодействия (A+B вместе vs порознь)
  - Условный эффект порядка (A→B vs B→A | оба есть)
- **Меньше confounding** между пассами
- Лучшая статистическая идентификация каузальных эффектов

## Научная ценность

### Для phase ordering research:
1. **Корреляционные графы переоценивают** важность парных переходов (2652 рёбер → только 358 каузальных)
2. **Фиксированная длина маскирует** каузальные эффекты (1 ребро → 358 с переменной)
3. **Переменная длина критична** для каузального вывода в compiler optimization
4. **Позиционные эффекты** (рано/поздно) важнее, чем парные переходы для многих пассов

### Для практики:
- Короткие последовательности (10–30 пассов) часто **эффективнее** полного набора
- Для простых программ (crc32, bitcount) короткие последовательности дают **огромный выигрыш** (38x, 3x)
- Для сложных (rsynth, jpeg) может потребоваться длинная последовательность
